# Pong - Documentation branch

This branch hosts documentation for the Pong project, divided in Commercial, Technical and Management documentation.

### Commercial

The `commercial.md` document acts as a user manual, a friendly introduction to the Pong application, detailing its core functionalities in a non-technical way.

### Technical

The `technical` folder hosts the JavaDOC documentation for the project, produced with `./gradlew javadoc`.

### Management

The `management` folder hosts all the documents related to the management of this project: sprint details, product backlog, repository management, definition of done.
