# Pong commercial User guide

## Welcome to Pong

Pong is a local two-player game for the desktop. Challenge a friend, control your paddles, and be the first player to reach the winning score.

Everything you need is available from the game’s simple menu system, so you can start playing in seconds and adjust the experience whenever you like.

## Start playing

Launch Pong to open the Main Menu. Choose **Start Game** to begin a new match.

Each new match starts with:

- Both players at zero points.
- The ball and paddles in their starting positions.
- The current game settings from the Options menu.

## Controls

The default paddle controls are:

| Player | Move up | Move down |
| --- | --- | --- |
| Left player | `W` | `S` |
| Right player | `↑` | `↓` |

Hold a movement key to move the corresponding paddle. Release it to stop moving.

Controls can be changed from **Main Menu → Options**.

## How to play

Keep the ball in play and return it past your opponent’s paddle. When a player misses the ball, the opposing player receives a point and the round resets.

The first player to reach the configured winning score wins the match. The default winning score is 5 points.

The score remains visible when the match ends, so both players can clearly see the final result.

## Pause and return to the menu

Press `Esc` during gameplay to open the pause menu. While the pause menu is open, the match is suspended.

From the pause menu you can:

- Choose **Resume** to resume the current match.
- Choose **Quit match** to stop the current match and return to the Main Menu.

The same `Esc` key can be used to close the pause menu and continue playing.

## After a match finishes

When a player reaches the winning score, Pong displays a clear winner message and stops normal gameplay. The final scores are preserved while the result is shown.

From the finished-match screen:

- Press `Enter` to start a new match immediately.
- Press `Esc` to leave the match and return to the Main Menu.

Starting a new match does not require restarting the application. The scores, ball, and paddles are reset while the configured game settings are retained.

## Customize your game

Open **Options** from the Main Menu to tailor the match to your players. You can adjust:

- **Winning score**: how many points are needed to win.
- **Ball speed**: the ball’s starting speed.
- **Paddle speed**: how quickly the paddles respond to movement keys.
- **Paddle controls**: the keys used by each player to move up and down.

Choose **Save** to keep your changes. If a value is not valid, the game explains the problem so you can correct it. Saved settings are used when the next match starts.

Options are available from the Main Menu and are not opened from the pause menu, keeping the current match focused and easy to resume.

## Quick reference

| Action | Input |
| --- | --- |
| Start a match | Main Menu → **Start Game** |
| Pause gameplay | `Esc` |
| Resume from pause | `Esc` or **Resume** |
| Return to Main Menu from pause | **Quit match** |
| Start a new match after victory | `Enter` |
| Leave the finished match | `Esc` |
| Open settings | Main Menu → **Options** |

## A great match in three steps

1. Choose **Start Game**.
2. Move your paddle and return the ball to your opponent.
3. Reach the winning score first and celebrate the victory.

Have fun playing Pong!
